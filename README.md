 Description

This is a simple Task Management System developed using PHP, MySQL, HTML, and CSS.
The project allows users to add, manage, and organize tasks efficiently.

The backend is built using PHP with a MySQL database connection, and the frontend is styled using CSS for a clean and user-friendly interface.

This project demonstrates basic CRUD operations and database connectivity in web development.

 Features

Add new tasks

Store tasks in MySQL database

Simple and clean user interface

Organized file structure

Database connection using conn.php

SQL file included for database setup

 Technologies Used

PHP

MySQL

HTML5

CSS3

 Project Structure

conn.php → Database connection file

add task.php → Handles task insertion

style.css → UI styling

project_1.sql → Database structure

⚙️ How to Run the Project

Install XAMPP / WAMP

Start Apache & MySQL

Import project_1.sql into phpMyAdmin

Place project folder inside htdocs

Open in browser:

http://localhost/your-folder-name
